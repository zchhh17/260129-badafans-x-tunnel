# X-Tunnel 技术文档

## 1. 项目简介

X-Tunnel 是一个高性能、抗干扰的隧道代理工具，旨在通过 WebSocket (WSS) 协议构建安全的通信隧道。它采用先进的加密技术和多路复用机制，能够有效穿透防火墙和 CDN，为 TCP 和 UDP 流量提供隐蔽、稳定的传输通道。

## 2. 技术架构

X-Tunnel 采用经典的 C/S（Client-Server）架构，主要包含以下核心组件：

### 2.1 传输层：WebSocket + TLS 1.3
*   **通信载体**：利用 WebSocket 协议（WSS）作为底层传输载体。WebSocket 协议天然兼容 HTTP/HTTPS 基础设施，能够通过 Nginx、CDN 等中间件，且难以被流量特征识别系统阻断。
*   **安全加密**：强制使用 TLS 1.3 进行链路加密，确保数据在传输过程中的机密性和完整性。

### 2.2 隐私增强：ECH (Encrypted Client Hello)
*   **抗 SNI 嗅探**：集成 ECH（Encrypted Client Hello）技术。在 TLS 握手阶段，Client Hello 消息（包含目标域名 SNI）被加密封装，防止中间人通过 SNI 嗅探获知目标服务域名，从而极大增强了抗审查能力。
*   **DoH 集成**：内置 DNS-over-HTTPS (DoH) 客户端，用于安全地获取 ECH 公钥配置，防止 DNS 污染和劫持。

### 2.3 连接管理：多路复用与连接池
*   **连接池 (Connection Pool)**：客户端维护一个 WebSocket 连接池（`ECHPool`），预先建立并保持多条到底层服务器的 WSS 连接。
*   **多路复用 (Multiplexing)**：采用自定义二进制协议，在单条 WebSocket 连接上并发承载多个用户 TCP/UDP 会话。这避免了为每个用户请求频繁建立 TLS 握手的开销，显著降低延迟并提高吞吐量。

## 3. 核心原理

### 3.1 协议封装
X-Tunnel 定义了一套精简的二进制帧格式，用于在 WebSocket 隧道中封装用户数据：
```text
[Type (1B)] [ConnIDLen (1B)] [MetaLen (2B)] [PayloadLen (4B)] [ConnID] [Meta] [Payload]
```
*   **Type**: 消息类型（如 `MsgTCPData`, `MsgUDPData`, `MsgConnect` 等）。
*   **ConnID**: 唯一标识一个用户会话，实现多路复用。
*   **Meta**: 用于携带控制信息（如目标地址、IP 策略等）。
*   **Payload**: 实际的用户数据负载。

### 3.2 隧道建立与转发流程
1.  **初始化**：客户端启动时，通过 DoH 获取服务端的 ECH 配置，并建立 WebSocket 连接池。
2.  **请求拦截**：客户端监听本地端口（SOCKS5/HTTP/TCP），接收用户请求。
3.  **路由选择**：客户端为新请求分配唯一的 `ConnID`，并从连接池中选择一个可用的 WebSocket 通道（支持负载均衡）。
4.  **数据封装**：将用户的 TCP/UDP 数据封装为二进制帧，通过选定的 WebSocket 通道发送给服务端。
5.  **服务端解包**：服务端接收帧，解析 `ConnID` 和 `Payload`。如果是新连接，则根据 `Meta` 中的目标地址发起向目标服务器的连接。
6.  **双向转发**：建立映射关系后，服务端将目标服务器的响应封装回传，完成双向数据透传。

### 3.3 UDP 穿透 (UDP over WebSocket)
项目实现了完整的 UDP 转发支持（包括 SOCKS5 UDP Associate）。UDP 数据包被封装在 WebSocket 帧中传输，服务端在接收后会通过原生 UDP Socket 发送给目标，并将响应回传。这使得 X-Tunnel 能够完美支持 DNS 查询、QUIC、视频通话等 UDP 应用。

## 4. 带来的效果与优势

### 4.1 极致的隐蔽性与抗干扰
*   **HTTPS 伪装**：流量特征与普通 HTTPS 网页访问完全一致，难以被防火墙识别。
*   **ECH 隐私保护**：彻底隐藏了 SNI 信息，使得流量审查设备无法通过域名阻断连接，大大提高了存活率。

### 4.2 高性能与低延迟
*   **连接复用**：通过连接池和多路复用技术，消除了 TCP/TLS 握手的重复开销，首包延迟（TTFB）显著降低。
*   **内存优化**：大量使用 `sync.Pool` 进行缓冲区复用，减少 GC 压力，支持高并发数据吞吐。
*   **智能聚合**：支持写入队列的智能聚合（Batch Write），在网络拥塞时自动合并小包，提高传输效率。

### 4.3 灵活强大的功能
*   **全协议支持**：同时支持 TCP 和 UDP 转发，内置 SOCKS5 和 HTTP 代理服务器。
*   **服务端前置代理**：服务端支持通过 SOCKS5 代理连接目标（链式代理），可用于隐藏服务端真实 IP。
*   **精细化控制**：支持 IPv4/IPv6 偏好策略、CIDR 白名单访问控制、UDP 端口黑名单等高级功能。
*   **Token 认证**：内置轻量级 Token 认证机制，防止未授权访问。

## 5. 总结
X-Tunnel 不仅仅是一个简单的代理工具，它是一个集成了现代网络安全技术（TLS 1.3, ECH）和高性能网络编程模式（多路复用, 连接池）的隧道解决方案。它在保证极高隐蔽性的同时，不牺牲传输性能，非常适合对隐私保护和网络稳定性有高要求的场景。
